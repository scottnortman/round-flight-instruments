# Round Flight Instruments v0.1

First packaged bench release for the **Waveshare ESP32-S3-Touch-LCD-2.8C,
SKU 29086** (480 × 480, 16 MiB flash, 8 MiB PSRAM).

## Install

Download `round-instruments-v0.1-waveshare-29086.zip` and `SHA256SUMS.txt` from
this release. Verify the ZIP checksum, extract it, and follow its `INSTALL.md`.
The package includes the combined flash image, Python UART client, checksums,
build provenance and third-party notices. No Rust installation is required.

Use the board's UART USB connector. The CLI runs at **921600 / 8N1**, no flow
control. Back up your own factory firmware before flashing. Full instructions:
[installation guide](https://github.com/scottnortman/round-flight-instruments/blob/v0.1/docs/INSTALL-WAVESHARE.md).

## Included

- Simulated three-pointer altimeter with prominent altitude readout, readable
  Kollsman digits, and orange outlines on the two broad hands.
- Touch adjustment: hold the pressure window for 0.25 seconds, then release.
  Blue feedback confirms the press. Adjust in 0.01 inHg steps; 29.92 resets the
  draft. Apply commits; Cancel or 30 seconds of inactivity discards.
- Blue press feedback on all popup buttons and a short screen-press chirp,
  with `touch sound on|off|status` controls. Held contacts do not repeat.
- Shared desktop/board text CLI, character echo, validity diagnostics, and
  `sim takeoff 60` for a visible 0–10,000 ft climb with rendering statistics.
- Portable Rust state, rendering, input and sensor modules; GT911 touch and
  QMI8658 diagnostics. Shared I²C ownership and bounded worker communication.
- Browser gauge simulations and snapshots from the actual Rust renderer.

## Verification and limitations

72 Rust tests and five browser regression suites pass; workspace Clippy passes
with warnings denied. The combined release image was flashed and readback-verified
on the development board. Automated touch/CLI and climb checks pass.

Prior bench measurements reached 32.33 FPS during ordinary animation with IMU
polling, and 29.22 FPS during repeated overlay/setting activity. These are
workload measurements, not a guaranteed minimum rate. User bench checks confirmed
clean motion, touch feedback, Apply/Cancel, timeout and the standard-pressure button.

Only the altimeter has a hardware renderer. Settings are volatile. The IMU has
an unresolved stationary gyro offset and does not drive the gauge. Other gauges,
persistent settings, encoder input and faster communications remain future work.
**For bench/simulation use only; not validated or certified for flight.**
