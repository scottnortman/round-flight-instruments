# Round Flight Instruments v0.2.0

Released November 18, 2026 after the user confirmed that the latest firmware
and Windows application had been tested and work as expected.

Download the assets from the [v0.2.0 release](https://github.com/scottnortman/round-flight-instruments/releases/tag/v0.2.0).
Use the Windows installer on the MSFS 2020 PC and the firmware bundle for the
Waveshare ESP32-S3-Touch-LCD-2.8C, SKU 29086.

## What is included

- Six standard instrument faces, Combined, and DEBUG.
- Manual aircraft-profile editing, preview and live delivery with board acknowledgement.
- Corrected Combined VSI mapping and readable bold bank labels.
- Touch QNH editing on Altimeter and Combined. Only explicit Apply actions
  can request an aircraft pressure change; read-only, DEMO and calibration guards apply.
- Per-screen DEMO with restoration of current source readings.
- Guided IMU LEVEL/FULL 24 calibration, reviewed persistence and calibrated
  six-axis Madgwick attitude for bench use.
- Existing automatic MSFS/aircraft/USB reconnection, device UUID and saved gauge.

## Installation

1. Download `SHA256SUMS.txt`, the Windows installer and
   `round-instruments-v0.2.0-bundle.zip`; verify their checksums.
2. Run the installer. Close Round Instruments and all serial terminals before flashing.
3. Extract the complete bundle. Follow its `FLASH-INSTRUCTIONS.md` using the
   board's **UART USB** connector. The included script validates checksums and
   partition layout before opening the port. It writes bootloader, partition
   table and application only, preserving NVS settings and calibration.
4. Start Round Instruments, select the board and connect to MSFS 2020.
   Open the profile editor, select the intended aircraft and click
   **Use on connected board**. Check tray Status for confirmation.
5. Hold the dial center for one second, release, then select a screen.
   Tap the QNH box on Combined or use the Altimeter pressure control to edit.
   Only Apply requests a change; Cancel leaves the pressure unchanged.

See [host instructions](../MSFS-TEST-13.md), [profiles](../PROFILE-EDITOR.md),
[Combined controls](../CONSOLIDATED.md), [DEMO](../DEMO.md),
[DEBUG](../DEBUG.md), and [IMU calibration](../IMU-CALIBRATION.md).
The retained app may describe pressure editing as Altimeter-only in Status;
the accepted firmware also supports the guarded Combined QNH editor.

## Verification and limits

Fresh release checks: 297 Rust workspace/all-target tests with the MSFS feature
and strict all-target Clippy passed. Python executable integration tests and
package integrity checks are recorded in [release verification](../../verification/RELEASE-v0.2.0.md).
Prior hardware checks include approximately 32 FPS, zero blank frames in the
documented workloads, application readback and preservation of device settings.
The user confirmed functional acceptance of the latest firmware and app on
November 18, 2026; this does not imply that every aircraft has been qualified.

**Bench/simulation use only. Not validated or certified for flight.**
MSFS 2024 and DCS live integration are not included. Profiles remain manually
selected, not automatically matched to the simulator aircraft. Independently
referenced FULL-24 physical/dynamic IMU accuracy remains unqualified, and the
known high gyro-bias warning remains relevant. Strict constrained-CPU
zero-expiry performance is not established; bounded display hold can absorb
brief late frames. Multi-device management and faster transport remain future work.

The installer includes unmodified Microsoft SimConnect runtime with its
separate Microsoft license and notices. Project and third-party licenses,
source snapshots, manifests and checksums accompany the release.
