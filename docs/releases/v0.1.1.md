# Round Flight Instruments v0.1.1

Fixes unwanted buzzer chirps when touching inactive parts of the display.

Sound now follows the UI's accepted-press events: the active Kollsman window and
the five visible popup buttons. Blank dial areas, popup labels, hidden controls,
invalid/disabled displays and drags into a button stay silent. Holding does not
repeat. The 250 ms opening hold, blue feedback and release-only actions remain.

Requests are bounded and expire after 120 ms. Existing mute controls, nominal
40 ms pulse, 150 ms rate limit and I²C fault handling remain in effect.

Download `round-instruments-v0.1.1-waveshare-29086.zip` and `SHA256SUMS.txt`.
Verify the checksum and follow the included `INSTALL.md`; retain your original
factory backup. This package targets Waveshare ESP32-S3-Touch-LCD-2.8C SKU 29086.
The UART CLI remains 921600 / 8N1 / no flow control.

74 Rust tests and workspace Clippy pass. The combined image was flashed and
readback-verified; hardware touch/sound diagnostics and a climb test pass.
See [verification](https://github.com/scottnortman/round-flight-instruments/blob/v0.1.1/verification/RELEASE-v0.1.1.md)
for the measured results and physical acceptance.

This remains a bench/simulation prototype, not validated or certified for flight.
