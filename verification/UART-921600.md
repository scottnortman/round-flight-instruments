# UART speed update — November 1, 2026 (America/New_York)

Subsequent update: [board character echo and client negotiation](CLI-ECHO.md).

Installed application CLI: **COM5, 921600 baud, 8 data bits, no parity,
one stop bit, no hardware or software flow control**. Commands and safety
deadlines are unchanged. The Python CLI and shared hardware-test Link default
to this speed; `--baud 115200` allows the CLI to use earlier archived firmware.

UART0 switches speed after the existing driver is installed and pending boot
output is drained, before READY. ROM/boot/early initialization stays at 115200;
the generated SDK check still verifies that boot setting. Flash transfer stays
at 460800, independent of application communications.

The first test started during boot, encountered garbled framing, and failed.
A subsequent raw probe showed a rejected malformed command followed by a valid
status reply. After startup, all tests below passed. Wait for READY before
commands; reopen the Python client if boot noise causes a framing error.
